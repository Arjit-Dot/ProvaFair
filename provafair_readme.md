## 🚀 The Problem: The Illusion of Randomness
Whenever valuable assets are distributed by chance—such as state lottery jackpots, retail IPO allotments, or blockchain validator slots—we rely on random number generators. However, standard computers use Pseudorandom Number Generators (PRNGs) that are strictly deterministic. 

If an insider, a hacker, or a rigged machine knows the initial "seed" or the internal algorithm, they can perfectly predict the outcome. From the outside, a fair draw and a rigged draw look completely identical. This vulnerability has led to multi-million dollar exploits in both traditional lotteries and Web3 smart contracts.

## 💡 The Solution: Verify, Don't Trust
ProvaFair utilizes **Device-Independent Quantum Random Number Generation (DIQRNG)** to guarantee absolute fairness. 

Instead of blindly trusting the hardware or the code, our system simulates a live quantum Bell test on entangled particles. As the numbers are generated, the system calculates a real-time physics score based on the CHSH inequality:
*   **Score $\leq 2$ (Classical/Rigged):** The system detects deterministic, predictable algorithms. The draw is instantly **blocked**.
*   **Score $> 2$ (Quantum/Fair):** The system mathematically proves the numbers were generated by non-local quantum entanglement and could not have been predicted by anyone. The draw is **verified**.

## 🖥️️ Project Architecture

The ProvaFair platform is divided into two main interfaces:

### 1. The "Generate" Portal (B2B Admin Backend)
Used by organizations (e.g., IPO underwriters or lottery commissions) to execute draws.
*   Features a "Rigged/Classical" switch to demonstrate how the system catches fraud.
*   Features a "Live Quantum Circuit" switch to generate true randomness.
*   Displays the real-time CHSH score gauge to monitor the physical integrity of the draw.

### 2. The "Verify" Dashboard (Public Front-End)
Used by retail investors, players, and auditors to verify the fairness of a draw after it happens.
*   Users can search by `Draw ID`.
*   Displays the winning numbers alongside a green "Certified Physics Score" badge, providing mathematical proof of fairness.
